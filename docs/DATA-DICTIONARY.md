# 印刷损耗稽核字段定义

| 字段 | 类型 | 定义 |
|---|---|---|
| 工单 | 字符串 | 保留前导零，旧名为业务编号 |
| 修订号 | 整数 | 正整数，兼容版本列。最高修订的业务值一致时保留首次原始行 |
| 提交时间 | RFC 3339 时间 | 必须含偏移量，统一为 UTC，版本裁决以修订号为准 |
| 上机纸张 | 业务文本 | 必填，按业务段解析 |
| 刀版拼数 | 业务文本 | 必填，按业务段解析 |
| 上机废纸 | 业务文本 | 必填，按业务段解析 |
| 裁切废件 | 业务文本 | 必填，按业务段解析 |
| 每包张数 | 业务文本 | 必填，按业务段解析 |
| 原始备注 | 字符串 | 可空，可内含换行 |
| 外部记录值(合格张) | 十进制数 | 参照值。真实零值与找不到键分别表示 |

上机废计大纸张，裁切废计成品单件，损耗分别落在拼版前后。对账按合格张，尾包用于复核。

空字符串、`N/A`、`-`、`NULL`、`未知` 均拦在必填字段。`无` 可以表示空集合，按具体业务字段解释。
逐行记录保留物理起始行号。JSON 的计量值为十进制字符串。

## 流水线记录

运行清单保存来源和外部账的 SHA-256、规则版本、耗时、计算参数和创建时刻。
影子版本与重复行保留原始字段。复核按版本追加，旧版本提交返回 409。

交班清理按批次登记方式（撤回原文或保留受控证据）与凭据数量，版本追加。
清理后备注单元格为 `‹已清理#摘要›` 标记，记录附 `note_proof`：归一备注的
SHA-256 与字符数。保留方式的原始来源封存于受控证据，不出现在工作台与导出；
撤回方式不保留原文。导出附交班清理状态，不含备注原文。

导入原文件时指纹取源字节，编辑预览后以提交的 UTF-8 文本计算。
